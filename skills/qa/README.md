# QA — bổ sung sau

Chưa xây SKILL.md hoặc agent QA. Không cài như skill đang hoạt động.

[Checklist section hiện có](references/section-qa-baseline.md) được tách từ build-theme làm đầu vào: schema/placement, Theme Editor lifecycle, responsive, accessibility và runtime. Khi xây skill sẽ bổ sung phạm vi, cách lấy evidence và tiêu chí bàn giao. Checklist chưa phải kết quả QA.

Các skill build vẫn phải chạy kiểm tra phù hợp với thay đổi; không được coi QA chưa xây là lý do bỏ validation.

QA mọi theme variant phải kiểm tra [category trong Add section theo base `main`](references/section-qa-baseline.md#add-section-category-theo-base-main), kể cả section riêng của theme và preset vừa đồng bộ từ template.
