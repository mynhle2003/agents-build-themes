# Update base — bổ sung sau

Chưa có SKILL.md local riêng cho nhóm này. Chưa cài hoặc kích hoạt skill.

Phạm vi dự kiến: cập nhật base cá nhân từ upstream/main hoặc upstream/dev; cập nhật theme từ main; bảo vệ custom và composition; preview diff, Theme Check, một commit và push theo policy repo.

Khi xây skill, đọc AGENTS.md và docs/theme-customization-policy.md của repo đích. Không đóng gói lịch sử đồng bộ, SHA hiện tại, credential hoặc repo/store mặc định vào skill. Giữ quy tắc file lịch sử riêng main, hỏi từng option bị xóa, dừng nếu custom chồng lấn và không force-push/reset hard. Các lệnh hiện tại nằm ở hồ sơ local repo, không được chạy từ yêu cầu bổ sung skill.
